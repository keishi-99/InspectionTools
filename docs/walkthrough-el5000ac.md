# EL5000AC 通し実行の手順書(手順5-5c)

実機で、1台分を起動から転記まで通して動かし、結果と気づいた点を記録する。ここで見つかった点を、5-5d で直す。

- 対象: 新アプリ(`InspectionTools.App`)、製品 EL5000AC、1台
- 所要時間の目安: 検査の実作業を含めて、旧アプリで1台に掛かる時間と同じ程度
- 記録のしかた: 各ステップの「結果」欄に、○(期待どおり)、×(違った)、△(動いたが気になる)を書き、×と△は「気づいた点」に内容を書く。最後の表を、そのまま私に送ってもらえばよい

## 0. 準備

| # | 内容 | 結果 |
|---|---|---|
| 0-1 | 確認する版(マージ前は、この PR のブランチ `feature/ui-tuning`。マージ後は、最新の `main`)をビルドして、`InspectionTools.App\bin\...\` を実機の PC に置く(上書きコピーのとき、`keybindings.json` と `sessions` を消さないよう注意) | |

## 3. 検査(1台分)

画面のキーは、キー案内に出ているものを使う。どちらで操作してもよいが、**少なくとも1項目はキー、1項目はマウス**で行う。

## 5. 操作の補助

| # | 操作 | 期待する動き | 結果 |
|---|---|---|---|
| 5-1 | 作業項目や DMM を使う項目で「設定を再適用」(`F3`)を押す | その項目の測定器の状態を送り直す(本体で手動で変えたあとの戻しに使う) | |
| 5-2 | 「画面のキー」を無効にする | `Enter`、`F5` などが効かなくなる。案内が「画面のキー: 無効」に変わる。有効に戻すと元に戻る | |
| 5-3 | 「前面ホットキー」を有効にする。他のソフトにフォーカスを移して `]` を押す | 新アプリが前面に出る。最小化していても出る。無効に戻すと、`]` が他のソフトで打てる | |
| 5-4 | 台数を2に増やし、2台目の項目を1つ確定する。そのあと、台数を1に減らす | 2台目の列が出る。結果のある2台目が消えるので、「2台目の結果が削除されます」と確認される。「いいえ」で台数が戻り、「はい」で1台になる | |
| 5-5 | 通信中(測定器の応答が遅いとき)にキーを押す | 通信中は画面が覆われ、キーやボタンが受け付けられない | |
